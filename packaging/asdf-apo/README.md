# asdf-apo

asdf plugin that installs `apo` from [GitHub Releases](https://github.com/baoulo/apo/releases).

```bash
asdf plugin add apo https://github.com/baoulo/asdf-apo.git
asdf install apo 0.2.0
asdf global apo 0.2.0
apo --version
```

Publish this directory to `baoulo/asdf-apo` (or keep developing from the monorepo path).
